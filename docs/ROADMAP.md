# Lộ trình phát triển 8 tuần

## Tuần 1 - Phân tích

- Xác định actor: Admin, Quản lý, Nhân viên kho.
- Chốt scope MVP và nghiệp vụ nhập/xuất.

## Tuần 2 - Thiết kế

- Hoàn thiện ERD từng service.
- Thiết kế API contract và event schema.

## Tuần 3 - Auth + Gateway

- JWT, role guard, account management.
- Gateway routing, middleware logging.

## Tuần 4 - Product + Supplier

- CRUD sản phẩm, danh mục, supplier.
- Search/filter/pagination.

## Tuần 5 - Inventory

- Kho, vị trí, stock levels.
- Low stock và aging alerts.

## Tuần 6 - Transaction

- Phiếu nhập/xuất, kiểm tra tồn, cập nhật tồn qua event.
- PDF export.

## Tuần 7 - Frontend + Report

- Dashboard, biểu đồ nhập/xuất, tồn kho.
- Export Excel/PDF.

## Tuần 8 - Docker hóa, test, deploy

- Compose, seed data, integration test.
- Viết tài liệu triển khai và demo script.
